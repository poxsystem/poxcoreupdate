Instalación paso a paso

Requisitos en la PC donde se instala: Windows 10/11, Node.js 18+ (se recomienda 20+, de nodejs.org) y MySQL Server 8 (o MariaDB) instalado y corriendo como servicio.

Paso 0 — Antes de empezar (una sola vez por PC)

  1. Instala Node.js desde nodejs.org (botón «LTS» → siguiente, siguiente). Al terminar abre una consola y escribe node -v: debe mostrar una versión.
  2. Instala MySQL Server desde dev.mysql.com/downloads/installer (elige «Server only» es suficiente). Durante el asistente define la contraseña del usuario root — la necesitarás en el paso 4. Asegúrate de que quede como servicio de Windows («MySQL80»).
  3. Copia la carpeta distribucion a la PC destino, por ejemplo a C:\PoxScore. Descomprímela primero si venía en ZIP — no instales desde dentro del ZIP.

Paso 1 — Abrir el instalador

  1. Entra a la carpeta copiada y haz doble clic en Instalar.bat.
  2. Se abre el asistente gráfico PoxScore-Setup (ventana con pasos). Si el PC no lo abre, el mismo .bat ejecuta el instalador de texto equivalente.

Paso 2 — Verificación de requisitos

  1. El asistente muestra si encuentra Node.js, npm y el servicio MySQL.
  2. Si algo falta, el asistente lo indica — instálalo (paso 0) y vuelve a abrir Instalar.bat.
  3. Pulsa Siguiente / Continuar.

Paso 3 — Credenciales de MySQL

  1. Servidor: localhost (déjalo así si MySQL está en esta misma PC).
  2. Puerto: 3306 (el estándar).
  3. Usuario: root (o el usuario que creaste en MySQL).
  4. Contraseña: la de MySQL del paso 0 — se escribe oculta (asteriscos).
  5. Nombre de la base de datos: poxscore (o el que prefieras — se crea sola).
  6. Pulsa «Probar conexión»: debe decir que conectó. Si falla, revisa que el servicio MySQL esté iniciado y la contraseña sea correcta.

Paso 4 — Instalación automática

Al confirmar, el asistente ejecuta solo (verás el log avanzar):

  1. Dependencias del proyecto y del launcher (npm install — la primera vez tarda varios minutos, necesita internet).
  2. Base de datos: crea la base y todas las tablas (Prisma).
  3. Aplicación web: queda lista en web\dist (ya viene compilada en el paquete).
  4. Acceso directo «PoxScore» en el escritorio.
  5. Opcional: Liga Ejemplo (6 equipos, 3 temporadas, playoffs) para practicar — responde S si la quieres, N si vas directo a tus datos.

Paso 5 — Terminar y abrir

  1. Al final pulsa «Abrir PoxScore» o cierra el asistente.
  2. Queda un icono PoxScore en la bandeja del sistema (junto al reloj) y el navegador se abre en http://localhost:4000.
  3. Listo: sigue con la sección 2 «Primeros pasos» para crear tu liga.

1. Introducción

PoxScore es el sucesor moderno de BallScore/BallStat: anota juegos de baseball y softball jugada por jugada (pitch a pitch), calcula automáticamente boxscores, planillas, estadísticas ofensivas, de pitcheo, de fildeo, situacionales y sabermétricas, administra ligas con posiciones, playoffs y temporadas, y mantiene el historial de por vida de cada jugador estilo Baseball-Reference.

Principio central: todo se deriva del stream de eventos del juego. Si algo se anota mal, «Deshacer» elimina la última jugada y todo el estado se recalcula solo — no hay correcciones manuales de estadísticas.

2. Primeros pasos

  1. Ligas → Nueva liga: nombre, año y deporte (baseball 9 entradas / softball 7).
  2. Entra a la liga → Equipos → «Nuevo equipo» por cada participante.
  3. Entra a cada equipo → arma el roster manualmente, por importación TXT/CSV o por movimiento por lote desde otro equipo.
  4. Juegos → programa juegos manualmente o genera el calendario completo con un clic.
  5. Abre un juego → define alineaciones → «Iniciar juego» → anota desde la pantalla de anotación.

4. Equipos y rosters

  • Alta manual: número, nombre, apellido, batea/tira, posiciones, foto (📷).
  • Importar CSV/TXT: pega o sube un archivo. Formato simple: Nombre,Apellido,POS (ej. Alexis,Lara,SS; varias posiciones separadas por comas). También acepta el CSV completo numero,nombre,apellido,batea,tira,posiciones. Omite encabezados y duplicados.
  • Mover por lote: checkboxes en el roster → «Mover N →» al equipo destino (distingue equipos homónimos por liga/año). El jugador conserva su ID → todo su historial lo sigue.
  • Baja/alta: desactivar un jugador no borra su historial.
  • ✏️ Editar: corrige nombre/abreviatura del equipo (botón junto al nombre) y nombre, apellido, #, batea/tira y posiciones de cada jugador (✏️ en el roster).
  • Desde la tarjeta del jugador: «✏️ Editar stats» (bateo/pitcheo/fildeo de la temporada), «↔ Cambiar equipo» y «⛔ Dar de baja / ✓ Reactivar».
  • Plantilla de alineación: guarda/carga el orden típico del equipo (📂/💾 en el constructor de lineup).

5. Programación de juegos

Manual: Liga → Juegos → «Programar juego» (visitante, local, entradas). La liga asigna deporte y entradas por defecto.

Calendario automático: «📅 Calendario automático» genera un round-robin por jornadas: todos contra todos, alternando localía cada vuelta. Parámetros: fecha de la 1ª jornada, número de vueltas y días entre jornadas. Con N equipos impares, un equipo descansa por jornada. «🗑 Borrar programados» elimina solo juegos sin iniciar (los jugados/finalizados jamás se tocan).

Doble jornada: cuando un equipo juega dos veces el mismo día, su segundo juego se marca con un superíndice J2 (tercero = J3) en el listado de juegos — así se distingue cuál partido fue el segundo de ese equipo.

6. Anotar un juego

La pantalla de anotación (En Acción o desde el juego → Anotar) muestra: linescore en vivo, diamante con corredores, conteo B-S, paneles del bateador y lanzador (JOGO = este juego, TEMP = temporada + hoy en vivo), planilla estilo BallScore y los botones de jugada.

Flujo del turno

  1. Anota el conteo pitch a pitch (Bola / Strike / Foul) — el marcador B-S se actualiza.
  2. Cierra el turno con el resultado: HIT / OUT / EN BASE. Se abre la pantalla de avances.
  3. En avances, ajusta cada corredor a su base final (los valores típicos vienen precargados) y marca la notación defensiva (6-3, F8, E5…) para el fildeo.

8. Finalizar el juego

Al completarse las entradas reglamentarias con ventaja (o walk-off), el juego se marca FINAL solo y se abre la pantalla de decisiones: ganador (WP), perdedor (LP), salvamento (SV), holds (HLD), juegos salvados desperdiciados (BS) — con sugerencias automáticas. CG y SHO se detectan solos.

  • Empate: marca «empatado» — sin W/L en posiciones.
  • Forfeit: marcador oficial = 1 carrera por entrada reglamentaria, salvo que el perjudicado ya iba ganando (queda el real). Las estadísticas jugadas sí cuentan.
  • Suspendido: conserva todos los eventos y se reanuda después; no acumula temporada hasta finalizar.

9. Posiciones y estadísticas

Posiciones (tab Posiciones)

Tabla completa: G-P-E, PCT, juegos detrás (JB), carreras a favor/en contra, diferencial, racha (G3/P2/E1), últimos 10 juegos, forma de los últimos 5 (puntos verde/rojo/gris) y la matriz cara a cara — el registro de cada pareja de equipos entre sí. Los clasificados a playoff se sombrean en verde con 🏆.

10. Playoffs

Tab 🏆 Playoffs de la liga:

  1. Configura cuántos clasifican y cuántas rondas (semifinal+final, etc.).
  2. Pareos: manual (eliges local/visitante y «gana con N victorias»: 3 = al mejor de 5, 4 = mejor de 7) o 🎲 automáticos por posición (1° vs último, 2° vs penúltimo…). Con número impar de clasificados, el que sobra queda sentado automáticamente.
  3. Sentados: checkboxes por ronda — esperan rival en la siguiente.
  4. Series: cada tarjeta muestra el record, sus juegos y «＋ Juego N» para crear el siguiente juego ya vinculado.
  5. Avance: al llegar a las victorias necesarias el ganador se sella y pasa al pool de la siguiente ronda junto con los sentados. Los eliminados quedan listados.

11. Temporadas e historial de por vida

  • 🗓 Nueva temporada clona la liga al año nuevo con equipos y rosters activos. Solo reorganizas con el movimiento por lote.
  • Cada jugador guarda su historial completo por temporada: en su tarjeta, tab «Por torneo» muestra Equipos: A → B → C cuando se movió, con tabla de stints por equipo + fila TOT; tab «Por año» resume cada temporada; el log juego a juego marca el equipo usado en cada partido.
  • Los bloques de postemporada aparecen separados dentro de cada torneo.
  • 🔀 Fusionar jugadores (menú): para duplicados — típico al importar ligas donde un mismo pelotero quedó con una ficha por equipo. Se elige la liga que administras (solo salen sus jugadores) y aparece la tabla «Posibles duplicados»: nombres con más de una ficha. La fusión por lotes permite elegir cuál ficha queda y marcar las demás — todas se borran y sus números se suman de una vez. Debajo queda la fusión manual de a dos.

12. Reportes y sitio web

  • Reporte del torneo (tab Reporte): resultados, posiciones, totales por equipo, líderes por categoría, MVP, tablas completas — imprimible.
  • 🏆 MVP automático: el reporte «MVP de la temporada» calcula el jugador más valioso sin elección manual — Puntos = WAR* ofensivo + WAR* de pitcheo ×0.75 + tinta ×0.25 (la tinta topea en 3.0; el WAR de pitcheo se descuenta como hacen los votantes de MLB — el as que lanza todos los juegos acumula WAR más rápido). La tinta pesa los lideratos estilo MLB (Black Ink): 4 pts por liderar AVG·HR·CI·G·ERA·K, 3 pts R·H·SLG·OPS·IP·SV, 2 pts 2B·OBP·BB·BR·WHIP·CG y 1 pt 3B·HLD·SHO. Los empates cuentan para todos los líderes (co-líderes, como en MLB). La tabla de candidatos muestra el desglose: WAR ofensivo, WAR de pitcheo, puntos de tinta y los departamentos que cada uno lidera.
  • Sitio web estático: un solo HTML navegable (portada, standings extendidos, equipo, jugador, boxscore con pitcheo por equipo + decisiones y recap, líderes, records, matchups) — súbelo a cualquier hosting o compártelo directo.
  • Reportes por juego: compuesto, situaciones y vs rival — imprimibles desde la página del juego.

13. Respaldo de datos

  • Menú Respaldo — tres opciones:
    • ⬇ Respaldo completo: toda la base de datos en un solo archivo .json — ligas, temporadas, equipos, series de playoff, jugadores, juegos, alineaciones, eventos jugada a jugada y acumulados de temporada (incluye las correcciones hechas con ✏️).
    • Respaldo por liga: elige la liga en el selector y pulsa ⬇ Respaldo de liga — mismo formato pero solo esa liga (útil para pasar una liga a otra PC o reinstalarla sola).
    • Restaurar: elige un archivo .json exportado y pulsa ⬆ Restaurar — inserta los datos respetando los IDs; los registros que ya existen se omiten (no duplica ni borra lo que ya está).
  • Recomendado: respaldo completo al cerrar cada jornada y al final de la temporada (antes del rollover).
  • Respaldo automático a disco: el servidor guarda solo un respaldo JSON en server\backups\ — al arrancar, cada 6 horas y cada vez que cierra un juego. Conserva los últimos 30 (rotación). En la página Respaldo se ven los archivos y hay botón «⬇ Respaldar ahora».
  • También hay respaldo de nivel base de datos: scripts\backup.ps1 (mysqldump).
  • ⚠ Si restauras un respaldo de liga en una base que ya la tiene, los datos existentes quedan como estaban (no se sobreescriben) — para reinstalar una liga desde cero, bórrala primero.

14. Usuarios y roles

  • Menú 👥 → crear usuarios. Mientras no haya ninguno, la suite queda abierta (modo local de una sola PC).
  • Al crear el primer usuario (hazlo admin), las escrituras piden sesión:
    • admin: todo — ligas, equipos, jugadores, usuarios, respaldo, publicación, importar.
    • anotador: anotar y administrar juegos (alineaciones, jugadas, cerrar juego).
    • visita: solo lectura.
  • La lectura (ver tablas, boxscores, estadísticas) nunca pide clave — ideal para que el público consulte.
  • Borrar el último usuario devuelve la suite al modo abierto. El botón 👤 del menú inicia/cierra sesión.

15. Compartir y exportar

  • 🔗 Vista en vivo: en la página del juego — copia un link público (/en-vivo/…) de solo lectura que se actualiza solo cada 10 s. Compártelo por WhatsApp para que cualquiera siga el marcador.
  • 📤 Tarjeta: descarga una imagen PNG del resultado (marcador + destacados) lista para redes sociales.
  • 📊 CSV: en Posiciones y en cada tabla de Estadísticas — descarga la tabla para Excel (separador «;», acentos correctos).
  • 📄 Imprimir / PDF: el reporte de liga abre el diálogo de impresión — elige «Guardar como PDF» para un PDF oficial.
  • 🖨 Alineación: tarjeta de alineación imprimible para entregar al umpire (orden, posiciones, banca, ampáyers).
  • ⚖️ Comparar: menú ⚖️ — dos jugadores lado a lado; selector de carrera o año específico; la barra verde marca quién gana cada categoría.
  • 🏆 Playoffs: el tab muestra el bracket visual por rondas (ganador en verde, sentados marcados).
  • Desempate: ✏️ Editar en la liga → regla de desempate (porcentaje / cara a cara / diferencia de carreras).
